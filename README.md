# 🛒 Complete MERN Stack Shopping Platform

A feature-rich, full-stack e-commerce application built using the MERN stack (MongoDB, Express.js, React.js, Node.js). This platform provides a complete online shopping experience for customers along with a dedicated admin management dashboard.

---

## 🌟 Key Features

### 👤 User Features
- **User Authentication:** Secure signup, login, and profile management using JSON Web Tokens (JWT) and BCrypt password hashing.
- **Product Catalog:** Browse products by categories, search items, and view detailed product specifications.
- **Cart & State Management:** Dynamic shopping cart management powered by Redux Toolkit.
- **Payment Integration:** Secure checkout workflow integrated with payment gateways.
- **Order Tracking:** Real-time order placement, confirmation, and status history.
- **Email Notifications:** Automated email updates for password resets and order confirmations.

### 🛡️ Admin Dashboard Features
- **Product Management:** Full CRUD operations (Add, Edit, Delete, View products) with image uploads via Cloudinary.
- **Order Management:** View, update, and manage customer orders and delivery statuses.
- **User Management:** Monitor registered users and administrative permissions.

| Layer | Technologies Used |
